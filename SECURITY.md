# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please do **not** open a public issue.

Instead, report it privately by opening a [security advisory](https://github.com/hurzelpurzel/hibersap-maven-plugin/security/advisories) or by contacting the maintainer directly.

Please include:

- A description of the vulnerability and the affected version(s)
- Steps to reproduce, if possible
- Any impact or severity assessment

We appreciate your help in keeping this project secure.
